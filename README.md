<td width="33%" valign="top">

<div align="center"><h3>🧠 AI Data Analytics Engine</h3></div>

**Natural language → SQL → visual insight, end to end.**

Converts plain-English queries into optimised SQL with automatic result visualisation — making database analytics accessible without knowing a line of SQL.

- NL-to-SQL with schema-aware query generation
- Auto-selects chart type based on result shape
- Handles multi-table schemas + ambiguous queries
- Edge case coverage: nulls, empty sets, aggregation conflicts

**Hard part:** Generating *correct* SQL from ambiguous language requires understanding both linguistic intent and relational algebra simultaneously.

<!-- ── Project 2 ── -->
<td width="33%" valign="top">

<div align="center"><h3>📡 NeuroMesh</h3></div>

**Disaster-resilient, infrastructure-free mesh communication.**

Ad-hoc mesh networking simulator for connectivity in disaster zones where all central infrastructure has failed — nodes self-organise, route dynamically, and heal autonomously.

- Dynamic routing with adaptive topology reconfiguration
- Node failure sim with autonomous mesh re-convergence
- Bandwidth-aware packet prioritisation for emergency signals
- Models real LoRa/RF hardware constraints in simulation

**Hard part:** Self-healing networks that maintain low latency *and* correctness as nodes drop is a classic distributed systems challenge — solved from scratch.

<td width="33%" valign="top">

<div align="center"><h3>⚡ Titan HFT</h3></div>

**High-frequency trading engine built for microsecond-grade latency.**

A simulated HFT execution engine modelling real market microstructure with order book management, strategy execution, and latency benchmarking.

- Lock-free order book with O(log n) price level ops
- Simulated co-location latency model (network + compute)
- Strategy layer: market making, arbitrage, momentum
- Benchmarked pipeline: sub-100µs order processing

**Hard part:** HFT demands correctness *and* speed at once — every allocation, branch, and cache miss is a deliberate performance decision.
